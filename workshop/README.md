# Workshop

Each subfolder here is its own project.

```
workshop/
├── project-one/
├── project-two/
└── ...
```

To start a new project, create a new folder inside `workshop/`.

`index.html` in this folder links to every project; add a line there for each new one.

## Design rules

- Black (`#000`) and white (`#fff`) only, unless a project asks for more.
- No corner radius anywhere: every UI element is sharp-cornered.
